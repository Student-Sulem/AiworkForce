Only an assistant reply carries the source label and the "Send for approval" action; there is nothing to approve about something the user typed themselves. An employee's reply is Markdown, rendered to safe HTML by the `markdown` filter (marketing/markdown.py, which escapes before it generates). What the person typed is NOT run through it: they typed text, not markup, and it should appear exactly as written. static/js/chat.js does not re-implement any of this. The JSON endpoint returns the same server-rendered HTML, so a reply looks identical whether Django or JavaScript put it on the page.
