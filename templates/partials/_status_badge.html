{% comment %} A status pill. INCLUDE CONTRACT status required str the machine value, e.g. "published" label optional str human-readable text, normally the model's get__display. Used verbatim. tone optional str explicit override, skipping the mapping below dot optional bool render a leading status dot The |title filter is applied only to the raw `status` fallback. A supplied `label` is already human-readable, and title-casing it would turn "Submitted for Review" into "Submitted For Review". WHY THIS PARTIAL EXISTS The old templates wrote class="badge-{{ object.status }}", which produced an unstyled class for every status the stylesheet had not anticipated -- paused, completed, offline, replied, qualified, unresponsive, sent, opened and bounced all rendered as bare, unstyled text. Mapping status to tone in one place means an unknown value degrades to a neutral pill instead.
